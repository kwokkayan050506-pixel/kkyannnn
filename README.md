# Mini Game Website
browser-based games built with HTML, CSS, and JavaScript (DOM manipulation).

## Games
- **Chrome Dino-style endless runner**: jump, collision detection, increasing speed, score tracking.
- **Whack-a-Mole**: random mole spawning, click/tap scoring, timer, restart.
- **Gem Rush**: collect gems within a time limit, with score tracking

## Tech Stack
- HTML
- CSS
- JavaScript (DOM manipulation)
